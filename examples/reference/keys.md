# Key reference

You're two directories deep now — this file lives in `examples/reference/`,
and every relative link still resolves because targets are anchored to the
*document's* directory, not wherever you launched mdview from.

## Moving

| Key | Action |
|-----|--------|
| `j` / `k` | one line |
| `SPACE` / `b` | page |
| `d` / `u` | half page |
| `g` / `G` | top / bottom |
| `]` / `[` | next / previous heading |

## Searching

| Key | Action |
|-----|--------|
| `/` / `?` | search forward / backward |
| `n` / `N` | next / previous match |

Search is smartcase: lowercase queries ignore case.

## Following

| Key | Action |
|-----|--------|
| `o` | label the visible links |
| `Backspace` / `ctrl-o` | back |
